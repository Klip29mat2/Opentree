# OpenTree 🌲

OpenTree is an experimental node-based procedural tree editor built with modern web technologies.

The goal of OpenTree is to create an intuitive visual workflow for generating and editing procedural vegetation, inspired by tools like SpeedTree, Blender Geometry Nodes, and Houdini.

## Features

* 🌱 Node-based editor powered by React Flow
* 🌲 3D viewport using Three.js / React Three Fiber
* 🔧 Procedural tree generation system (in development)
* 🎛️ Interactive parameters through nodes
* 📦 Project-based workflow with save/load support
* 🖥️ Desktop application powered by Electron

## Vision

OpenTree aims to make procedural vegetation creation more accessible by combining a visual node graph with real-time 3D feedback.

Instead of manually editing complex parameters, users will be able to build trees through a modular system:

```
Seed → Trunk → Branches → Leaves → Materials
```

Each node represents a step of the generation pipeline and can be customized independently.

## Status

🚧 Early development

The project is currently focused on building the core editor architecture, node system, and real-time 3D visualization pipeline.
